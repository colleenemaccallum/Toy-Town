# Narrator lines (Colleen's voice)

The characters never talk. Colleen records each line on her phone, and the game plays it at the right moment.
Save each recording as an **.m4a** file (the iPhone Voice Memos format) with the exact name below, in `audio/narrator/`.
If a file is missing, the game just stays quiet at that moment. Words are a draft: say them however feels natural,
or swap in the matching line from the story bible script.
